Design principles

  • Evidence before claim: every finding has a source.
  • Say "not found" instead of guessing.
  • "Worth reviewing", never a diagnosis or instruction.
  • Severity is icon + text + color, never color alone.
  • Readable in about a minute.
  • Privacy is visible, not hidden.

Accessibility

  • Text contrast 4.5:1 or better.
  • Real links and buttons, visible focus.
  • RTL layout with logical properties.
  • Icons always paired with text.

Pilot metrics

  • Time-to-Review
  • Findings Recall
  • Citation Faithfulness
  • Refusal Rate
  • Mark-as-reviewed rate
